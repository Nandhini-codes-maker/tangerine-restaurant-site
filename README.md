# Tangerine restaurant website

A static, multi-screen restaurant website with Home, Menu, Our Story, Contact, and Reservations screens. All menu content and photos are included in `index.html` and `assets/`. The site uses no backend, database, Python, or build tools.

## Preview locally

Open `index.html` in a web browser. The site and its images work directly from the project folder.

## Publish on GitHub Pages

1. Replace the sample restaurant address and phone number in `index.html`.
2. Create a **public** GitHub repository and upload `index.html`, `README.md`, and the complete `assets` folder to its root.
3. In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose the `main` branch and `/(root)`, and save.
4. After GitHub Pages finishes building, the public URL appears under **Settings → Pages**. It will usually be `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`.

The reservation screen links to the restaurant by phone. This static website does not collect, send, or save reservation requests.
